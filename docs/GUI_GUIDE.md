# 桌面交互界面

双击项目目录中 **软件\启动界面.bat**。已有 Python 环境，无需安装额外 UI 依赖，也无需启动浏览器服务。结果可直接在软件审查窗口中查看；离线 HTML 作为备用文件保留。

## 先体验现成案例

1. 点击「载入演示」，载入两张剖面及已经确认的图例/坐标。
2. 切换「方法与参数」，勾选需要的算法。默认 DTW、图匹配、Markov；GNN/Jev/Laya 可单独勾选，仍遵守人工复核规则。
3. 在底部选择输出位置，点击「开始识别与匹配」。
4. 「运行日志与结果」显示后台进度；完成后双击结果行打开软件内审查窗口，或点击「打开已有审查文件」载入历史 `review_manifest.json`。

## 使用自己的图片

1. 「添加图片」支持多选 PNG/JPEG/TIFF。导入时在后台**自动定位彩色主图、检测图例色块，并调用本地 Windows OCR 识别图例文字**。项目外图片只读导入，副本保存于 `输入数据/imported`，不修改原文件。
2. 双击剖面，绿色矩形为坐标 ROI，青色曲线是实际地层内容外轮廓，粉色曲线是尚未确认性质的内部空洞，黄色框为图例色块。图例会在整张图片搜索，所以主图 ROI 内的空白区同样可找到。规则彩色色块列中间若只有一个白色/空心格，系统会结合上下色块、间距、对齐与框内标记提出候选，但不会自动确认其岩性。双击下方图例行核对/改正完整岩性名称，确认后标记为「是」；同岩性应使用相同规范名称。
3. 核对编号、真实 station、共同坐标基准、物理单位和范围。新增图片的物理范围暂用像素大小占位，配准默认未确认；自动主图框通常不含坐标轴，所以物理范围尤其需要核对。正确后勾选「已核对主图/图例位置」及配准确认。
4. 检测有遗漏或框选不准时，用「框选绘图区」「框选图例色块」调整；内容边界不准时选择「逐点勾画内容外轮廓」，沿直线端点和曲线采样点依次点击，再按「完成当前轮廓」。明确的图内非地层区域使用「逐点勾画非地层孔洞」。右键或「撤销轮廓点」可回退。也可以再次点击「自动定位主图/图例」或「识别图例文字」。重复检测保留已确认的设置；需要替换已经确认的主图时，先取消位置确认。
5. 需要时框选文字/注释排除区或断层区域。断层区域会触发保守复核。保存剖面设置。
6. 对每张图完成设置；通过上移、下移调整顺序，确保 station 严格递增。

现有图片 manifest 或结构化 sections.json 可通过「打开配置/地层 JSON」载入，不必重复框选。JSON 和模型文件需位于项目内。多页 TIFF 应在 manifest 明确 page 后载入。

自动定位针对规则彩色软件导出图，通过大面积连通区域、矩形色块、与主图颜色重复及图例排列进行交叉检查。图例搜索不剔除主图矩形，只剔除已识别的实际地质内容，因此能处理位于主图内部空白区的图例。多个相近主图不自动强选；灰度、复杂纹理和非矩形图例可能需要手工定位。OCR 依赖系统已经安装的语言能力，不联网、不下载模型、不需要 API Key；缺少语言支持时仍保留色块建议，文字手工填写。

OCR 是建议而非地质语义认证：截断、错字、不同命名都需核对。未确认名字不会参与可靠连续匹配；自动范围未核对时，区域质量最高 0.65，不能绕过自动接受门限。确认近白色图例后，封闭白色区域才允许作为地层候选；包含图例框的白区仍被排除。`输入数据/实验` 中两张真实剖面已经加入自动回归：P11 检出 11 个图例候选，P101 检出 9 个，两者均包含一个白色 Fe3 候选。该结果只验证这两张图的版面定位，没有真实地质图大样本识别精度声明。

导入时还会对主图运行一次 OCR，橙色框表示文字、标高、孔号等杂项候选。运行识别后，任务目录 `recognition` 内的 `*_artifacts.png` 分开显示已接受网格/钻孔、文字墨迹、受保护地质界面和不确定线；`*_uncertainty.png` 分开显示内容边界、杂项邻域、内部不确定区域，以及红色的杂项回填地质交界。参数页可分别调整线状修复跨度、粗钻孔/线条最大半宽和文字修复跨度。系统先逐方向保守恢复，再沿已确认杂项通道连接同岩性区域，最后以已确认图例类别对整条技术通道和标签笔画完成颜色回填；不能判定为技术线的路径不会进入这一步。

匹配参数页列出 11 项软证据权重。岩性相同不在权重中配置，因为它是候选生成前的唯一硬条件。位置、上/下邻层岩性和形态默认权重较高但仍属于软证据；几何变化过大只会要求复核，不会删除同岩性候选。真实项目在有足够人工对应标注前，不建议根据单张结果反复手调到“看起来全匹配”。

若已经人工粗略清点过某张图，可填写“人工粗略地层数”。该值只生成数量偏差告警，不会改变面积门槛，也不会决定任何区域的保留、合并或删除。实际分割数量始终由统一识别参数产生。

## 人工审查与三维建模输入

1. 基准剖面的每个地层实例独立着色。同岩性共用色系并做小幅明暗变化；不同岩性使用相距较大的色相。
2. 目标剖面若与基准层对应，直接复用基准层颜色；split 的多个目标层使用同色；merge 使用多个来源色条纹；未对应目标层使用灰色。
3. 列表中每一行是一个按钮，左侧为基准剖面地层编号，右侧为目标剖面编号。一侧为空表示该侧没有对应层。点击后可查看置信度、原因和特征。
4. 「确认对应」「标记不对应」「仍需复核」只写入独立的 `manual_review.json`，不覆盖算法原始 `matches.json`。
5. 算法关系错误时点击「新增/修正对应」，分别输入两侧编号。软件再次执行岩性硬校验，异岩性或 UNKNOWN 不能建立对应。
6. 「导出三维建模输入」只导出当前方法中人工确认、两侧均有地层且没有重复占用的关系。输出 `modeling_input_方法.json`，包含完整边界、坐标、单位及 continuous/split/merge 对应；未确认、拒绝和 uncertain 关系不进入建模数据。

## 参数和输出

- 方法选择是真正的执行选择，不是仅隐藏未选方法的结果。单选 DTW/Markov 等也能导出完整页面。
- 接受代价越低、最小替代解间隔越高，判断越保守；参数不能覆盖异岩性禁止匹配的硬规则。
- “匹配候选预算”限制进入求解器的对应组合；任一剖面超过 80 层时，“大实例同岩性近邻数”控制每个组合保留多少个空间近邻。大实例模式的结果一律需要人工复核，增大参数只会扩大搜索范围，不会解除复核要求。
- 图例色差、第二候选间隔、最小区域面积、边界采样和接触间隔均可配置。勾选「覆盖各图片原有设置」后，统一参数才会替换加载的逐图参数；不勾选则保留原配置。
- GNN 可选择项目内 NPZ 权重。Jev 支持 mock/live。Laya 支持 mock、TypeSafe-compatible HTTP 服务和可选本地 Python 权重；两者接收完全相同的地质证据与问题。Key 从环境变量读取，界面不保存 Key。
- 「保存当前配置」保存图片、图例、方法、参数及输出位置，下次直接载入。
- 输出目录可自定义，但应放在 `F:\Desktop\3DSurfer\剖面地层匹配\输出数据` 内。
- 每次运行建立独立 `run_日期_时间_随机标识` 子目录，保存 request.json、sections.json、分割标签、JSON/CSV/HTML/PNG、run.log 与 status.json，不覆盖旧结果。
- 后台运行不阻塞界面。点击取消后在当前求解阶段结束时停止；不是强制杀死正在求解的线程。运行期间编辑的参数只影响下次任务。

启动失败时查看 `输出数据/日志/gui_error.log`。剖面编辑器可以重画整体内容外轮廓和非地层孔洞；单个地层内部边界的精细修订仍通过人工实例 mask 或结构化输入完成。
