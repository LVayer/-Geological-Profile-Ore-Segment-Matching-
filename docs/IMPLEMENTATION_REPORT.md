## 2026-09-24 正确性修订

识别流程已改成“完整路径杂项判别 → 粗线完整宽度恢复 → 线条/文字分别修复 → 图例类别分区回填 → 清理后重建内容域 → 地层实例提取”。路径两侧长期为不同类别时作为岩性分区边界保护；缺少技术线证据的连续构造线保持为构造不连续候选或不确定线，不依赖其文字名称。确认的钻孔中心线只在有限距离内吸收浅色低彩度像素，覆盖粗钻孔的完整宽度。逐像素和定向通道恢复后，剩余技术线/标签像素按已核对图例类别的最近可靠区域完成回填；类别相遇位置另存复核线，不允许空带继续切割地层。普通空白和不确定路径不参与回填。文字另加局部多方向恢复，以保护被标签截断的斜向薄层。

匹配规则同步修订：删除位置、边界和厚度的候选硬拒绝，只保留已知岩性完全相同这一硬门。位置、上下邻层岩性和形态为第二层软证据，其余权重更低；全部权重可在界面修改并写入输出。几何极端变化会标记复核而不会直接判为不相关。合成基准重新运行后，DTW、图匹配、Markov 仍为 45 条正确自动接受、0 条错误接受、12 条漏匹配，应拒判样本 36/36 被拒判。GNN/Jev/Laya 仍全部要求人工复核。

自动测试现覆盖路径级杂项/界面判别、清理后内容域、白色封闭地层、文字穿越薄层、通道内同岩性重连以及禁止跨普通空白连接。人工层数估计只用于审计，不能修改面积门槛或强制增删实例。

P101 当前按通用门槛完整复跑，结果保存在 `输出数据/地层识数/`。人工粗估约 112 仅作为审计字段；程序没有按该数量调面积阈值。粗钻孔完整宽度处理和图例类别回填后，候选实例由 176 降为 168，内容域覆盖率约 94.99%。颜色分类阶段回填 23,730 个已确认杂项像素，实例过滤后又回填 2,357 个，两个阶段的已确认杂项通道未回填数均为 0；最终单个地层轮廓内的未分配空洞也为 0。仍有约 10.8 万个内容域像素位于内容边界、杂项邻域或内部颜色不确定区，其中并非已确认技术线本体。当前数量仍超出粗估范围，状态保持人工复核，不能解释为已经得到 168 个真实地层。全套 94 项自动测试通过。输出包含独立颜色图、原图叠加图、编号图、杂项/轮廓诊断图、未分类诊断图、CSV/JSON 清单和 NPY 标签图。

## 当前测试表现

评测为 36 组合成案例，12 类情形 × 3 个测试种子；81 个源地层、57 条正对应真值边。训练种子与测试种子隔离，但来自相同生成族，规模不足以支持统计推广。

| 方法 | 自动接受正确边 | 自动误匹配 | 漏匹配边 | 真值边召回 | split / merge / pinch-out 事件 |
|---|---:|---:|---:|---:|---|
| DTW | 45 | 0 | 12 | 78.95% | 各 3/3 |
| 图匹配 | 45 | 0 | 12 | 78.95% | 各 3/3 |
| Markov | 45 | 0 | 12 | 78.95% | 各 3/3 |
| GNN（合成训练，复核） | 0 | 0 | 57 | 0% | 全部复核，不自动接受 |
| Jev（mock，复核） | 0 | 0 | 57 | 0% | 全部复核，不自动接受 |
| Laya（mock，复核） | 0 | 0 | 57 | 0% | 全部复核，不自动接受 |

前三种方法的接受精度是当前样本中的 45/45，源地层自动处理覆盖率为 45/81 = 55.56%（含尖灭）。应拒判的 36 个源地层全部保留复核。**零误匹配不能证明真实高准确率**；它伴随拒判和漏匹配。

六种方法的未经终审建议均包含 57 条正确边、12 条错误边，建议边精度为 82.61%；这是共同简单数据和回退模式下的结果，不能作为模型实力排名。GNN/Jev/Laya 没有自动接受边，接受精度为 null，而不是 100%。

无损 PNG/TIFF 在当前规则三层图上的像素 IoU 为 1.0；默认 JPEG 示例分别约 0.892、0.873、0.951，已分配像素精度 1.0，但有边缘漏分，故 JPEG 强制复核。只测了这个受控图形，不能外推到真实扫描图。详细数据见 `outputs/recognition-metrics.json`。

## 目前影响精准度的主要问题

1. 缺真实、完整、独立区域的专家标注，权重/门限/置信度尚未校准。
2. 重复岩性、纹理型图例、文字与构造线干扰，以及同色接触实例的分割存在信息不足。
3. 实际剖面间的尺度、基准、走向和空间距离必须正确；图像相似不等于三维连续。
4. 几何排序与有限像素接触图只能近似简单构造；薄夹层、断层和褶皱会导致拒判或漏匹配。
5. 合成训练只证明数据流和优化流程可用，不能证明 GNN 比传统方法好；当前五法结果差异也不足以形成排名。
