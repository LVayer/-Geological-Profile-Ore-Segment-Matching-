# 算法、分数与适用条件

## 公共候选与规则

将每个独立地层实例视为一个节点。候选 h=(S,T) 是同岩性节点集合之间的超边，只允许 1:1、1:N、N:1。S/T 不能同时为多节点，最大组大小默认 3。同岩性组先做空间跨度约束，再聚合面积、边界包络和外部邻居。跨越另一岩性的组合可保留为审查建议，但不会自动接受。

候选代价 = 特征向量和可配置软权重的点积 + 0.12×额外成员数。默认权重依次为位置 .25、厚度 .05、面积 .03、形态 .16、边界 .08、方向 .03、层序 .04、上邻层 .16、下邻层 .16、其他接触 .02、拓扑 .02。岩性不进入加权求和，而是在候选产生前实施唯一的地质硬门。位置和形态差使用共同物理尺度，厚度/面积采用绝对对数比；上下邻层使用岩性集合 Jaccard 距离；形态比较保留两条 64 点边界的函数形状。垂向包络不能解释复杂褶皱，遇到同列多段会降低质量。

所有方法使用同一宽松候选门限和严格终审。最终置信度是识别质量、地质代价、最优替代解差的保守组合，Markov 再受边际约束。这是**工程证据分数**，不是统计校准后的真实概率。

位置、厚度或边界差异不会删除同岩性候选。异常只作为软证据并把结果降为复核，因为断层、侵蚀、剖面方向与产状变化都可能造成真实连续层的几何突变。默认权重不是“前沿研究给出的通用最优值”：当前没有真实标注，无法可靠学习项目特定权重。Samant 等人的受约束 DTW 研究表明，复杂、空间变化明显的沉积序列中，全自动 DTW 不能盲信，知识约束、预处理和用户锚点能提高准确性；本系统因此保留人工审查和拒判，而没有靠扩大某个几何权重追求覆盖率。来源：[Paleoceanography and Paleoclimatology, 2025](https://agupubs.onlinelibrary.wiley.com/doi/10.1029/2024PA005082)、[Journal of Geophysics and Engineering, 2025](https://doi.org/10.1093/jge/gxaf077)、[blocked dynamic warping](https://doi.org/10.1190/INT-2016-0160.1)。

## 图像杂项预处理

工程图先做文字/图形分离再进入地层连通域。OCR 框只限定文字候选范围，框内仅字符笔画进入掩膜；大幅图的网格还需满足长轴向直线和近似周期重复。系统把整条线按两侧图例类别、路径延伸和重复结构证据分成技术线、岩性分区边界、构造不连续候选和不确定线；判断不依赖图上的文字名称。确认技术线后，先把检测中心扩展到有上限的浅色低彩度完整宽度。第一层修复采用相对方向最近分类一致规则；第二层要求杂项通道直接连接同类别的两个独立连通域；最终使用已核对图例类别的最近可靠像素对技术线和标签区域做完整 Voronoi 分区回填。两种重建类别相遇处保留复核线，但不再留下会切断连通域的空白。普通空白与不确定线不回填。随后从清理后的地质支撑构建最终内容域，人工/自动轮廓只作为最大边界。该流程借鉴工程图处理中“文字与图形显式分离、连通域/Hough 分组、上下文验证”的思路：[Dori & Velkovitch, 1998](https://www.sciencedirect.com/science/article/pii/S1077314297905853)、[IEEE dimension-set detection](https://ieeexplore.ieee.org/document/395662/)。

## DTW / 动态规划

状态 (i,j) 表示两侧已经处理的前缀。转移为源缺口、目标缺口，或消耗一组连续同岩性节点的超边。缺口代价 0.72；正对应为共享地质代价。全表递推后回溯最小代价路径。既允许一对多，也允许多对一，未采用普通 Hungarian 一对一限制。

此处是有地质代价和可变分段的 DTW 类序列匹配，非把二维轮廓点直接扔给经典 DTW。排序是几何上下顺序，非年代序列；非单调构造必须复核。

## 图匹配

每条候选超边一个二元变量，每个两侧节点还有一个未匹配变量。对每个节点约束：覆盖它的超边变量和未匹配变量之和 = 1。额外约束禁止不共享端点的两条超边产生层序交叉。以共享地质代价和缺口代价为目标，通过 SciPy/HiGHS MILP 全局求解。此约束允许完整 split/merge 成为一个事件，不允许同一实例在多个事件中被重复消费。

图结构体现在邻接特征、超边覆盖约束，以及最终映射接触边核查。它不是所有成对邻接差都进入目标函数的二次图匹配，后验冲突只降级复核，不进行无保证的强制修复。15 秒内没有证明最优就返回求解失败信息和未解决关系。

实现参考 [SciPy milp 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html)。

## Markov / 概率序列

使用与 DP 同样的分段状态格，加入组持续长度与上下文接触先验。转移权重 exp(-cost / temperature)，temperature 固定 0.22；前向/后向在 log 域计算，获得每条候选超边经过所有合法路径求和后的边际概率。最优路径仍由 Viterbi 得出。

这属于 semi-Markov 风格的分段概率对齐框架；不是训练得到的岩性 HMM。路径包含源缺口和目标缺口的不同次序，其路径组合会影响边际。独立测试枚举所有微型路径验证分区函数和边际，防止把局部 softmax 冒充序列后验。模型概率与地质真实正确概率之间仍需要专家数据校准。

## GNN

候选超边作为图节点，共享端点或相邻层序时建立图边。X 包含 11 个匹配特征、两侧组大小及常数。归一化邻接 Ahat = D^(-1/2)(A+I)D^(-1/2)。

```text
H = tanh(Ahat X W1)
p = sigmoid(concat(Ahat H, X) W2)
```

两次图传播和非线性是可训练的；原始特征残差帮助区分共享端点的互斥候选。二元交叉熵使用 NumPy 反向传播，有限差分测试独立检验梯度。每图等权、固定随机种子、L2 正则、250 轮，模型为无 pickle 的 NPZ。

p 以 30% 权重转换为候选代价，70% 保留地质代价，再经过相同全局图求解与终审。当前没有真实验证，不自动接受任何 GNN 结果。真正解除该限制需要单独的标注审查、校准和版本化审批设计，不能只调低一个接受阈值。

结构依据 [Kipf & Welling, Semi-Supervised Classification with Graph Convolutional Networks](https://arxiv.org/abs/1609.02907) 的归一化图卷积思想；本项目实现为候选图上的特定变体，并非该论文的复现实验。

## Jev

按照 [Venice Jev 官方说明](https://venice.ai/lp/jev) 的 `/api/v1/decisions`、`model/state/questions`、noul 问题结构构建请求。每条合法超边一个完整关系判断问题，不给模型机会创造未筛选的异岩性候选。正概率经验证后作为附加代价，仍受公共地质规则制约。

文档标注接口处于 beta，实际响应需用真实账号验证。当前模块支持 noul 数值或含 probability 的对象；响应字段不同须调整 parse，不能猜测解析。带令牌的请求禁止自动重定向；默认不重试付费 POST；响应大小、请求大小和超时都有上限。只记录错误类别，不记录 Key 或远端原始错误内容。

mock/fallback 使用共同地质代价生成建议，明确标记为 mock/fallback，均为 manual_review。离线注入 transport 只验证接口分支，不算成功访问服务。

## Laya

Laya 使用 `decisions.py` 中与 Jev 完全相同且确定序列化的 state、questions、instructions 和 criteria。适配层只允许改变模型名、认证、调用传输及响应中 noul 字段的读取，不能删减候选事实或重写地质问题。支持三种模式：mock；本机/HTTPS TypeSafe-compatible `/v1/systemone`；可选 Python `laya.load(..., subfolder="typed-decisions")`。接口依据 [Laya 开源仓库](https://github.com/NandhaKishorM/laya) 与 [One System 的兼容契约](https://github.com/rawwerks/one-system)；没有复制或安装其代码。

当前没有安装/下载约数百 MB 的开源权重，也没有在真实标注上测试 Laya。本项目默认 mock 并强制 `manual_review`。公开 Laya 文档显示 typed-decisions 微调检查点、基础检查点和多语言检查点表现差异显著，并提醒置信度需要按任务重新校准；因此不能把开源、低延迟或高模型置信度当成地质正确性证据。HTTP 明文只允许回环地址，远程地址必须 HTTPS；失败时不回退成“真实 Laya 成功”。

## 误差传播与冲突

当前匹配只读取上一个剖面对中高分 accepted 的位移作为小幅代价修正，最大 0.08；不直接继承结果。每个选中事件都重新求解“禁止此事件”的替代问题，用全局差额拒绝近似同优候选。源/目标所有实例均会出现在事件或未匹配记录中。

每种方法保留自己的输出。方法间不同的目标集合或事件类型进入 conflicts，无多数票覆盖。模型建议不同但最终均 uncertain，仍可保留建议冲突供检查。更多跨三个以上剖面的联合优化、真正的地质年代约束、走向/倾向三维约束和全局回溯是后续研究，不在当前实现中伪称已解决。
